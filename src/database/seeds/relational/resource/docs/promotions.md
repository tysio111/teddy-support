# Discount codes and promotions

## Using a discount code

Enter your discount code in the "Discount code" field at checkout and click "Apply". The discount is shown in the order summary before you pay. Codes are not case-sensitive.

Only one discount code can be used per order. Discount codes cannot be combined with each other or with items already on sale, unless the code says otherwise.

## Why a code might not work

A code may be rejected because:

- it has expired, or has already been used the maximum number of times;
- your basket does not reach the minimum order value for the code;
- it applies only to selected categories, and your basket contains none of them;
- it is a single-use welcome code linked to another email address.

You can ask our support assistant to check whether a code is valid.

## Newsletter welcome discount

Sign up for our newsletter to receive a 10% welcome code by email. The code is valid for 14 days, on your first order only, and on full-price items only.

## Seasonal sales

We hold two main sales a year: the summer sale starting in late June and the winter sale starting on 26 December. Sale prices are valid while stocks last. Items bought on sale can be returned within the normal 30-day return window.

## Price adjustments

We do not offer price adjustments if an item you bought is reduced later. You can return the item within 30 days and order it again at the new price.

## Gift cards

Gift cards are available from 50 PLN to 1000 PLN and are valid for 12 months. They can be used for several orders until the balance runs out, and can be combined with a discount code.
